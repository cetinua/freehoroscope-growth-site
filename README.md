# FreeHoroscope Growth Research

A static overview of FreeHoroscope's SEO research, growth priorities, roadmap, and measurement plan. The site is published as a standalone HTML page on GitHub Pages.

The authoritative research reports and datasets are maintained in the private repository [cetinua/freehoroscope-seo-research-data](https://github.com/cetinua/freehoroscope-seo-research-data). Access to those source links requires permission to view that repository. No private reports or datasets are included here.

This repository contains only the public mini-site: `index.html`, this README, and `.nojekyll`.
